# Bahraini Currency Detection 🇧🇭

## Overview
A currency detection application that uses a custom-trained YOLO object detection model to identify Bahraini currency in images.

## Features
- Detect Bahraini currency using YOLO.
- Upload images or capture photos using a camera.
- Display detected currency with bounding boxes and confidence scores.

## Technologies Used
- Python
- Ultralytics YOLO
- Roboflow (Dataset Preparation)
- Streamlit
- OpenCV

## How to Use
1. Open the Streamlit application.
2. Upload an image or take a photo.
3. Click **Detect Currency**.
4. View the detection results.

## Model
The YOLO model was trained on a Bahraini currency dataset prepared using Roboflow.
